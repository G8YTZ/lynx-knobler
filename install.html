Install Knobler

Flash the M5Dial firmware for Lynx directly from your browser — no Arduino IDE required.

Before you start:
  1. Connect your M5Dial to this computer with a USB-C cable (make sure it's a data cable, not charge-only).
  2. Use Chrome or Edge — this won't work in Safari or Firefox, they don't support the required browser feature (Web Serial).
  3. Close Arduino IDE's Serial Monitor or any other program that might be using the Dial's USB port.
Your browser doesn't support this. Please open this page in Chrome or Edge instead. This page needs to be served over HTTPS to flash a device — if you're seeing this on the published GitHub Pages site, please let us know.

After installing, the Dial will restart and walk you through Wi-Fi setup on its own screen. Full details in the written install guide if you'd rather flash via Arduino IDE, or if anything here doesn't go to plan.
